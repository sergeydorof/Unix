Допустим, есть директория test_files с текстовым файлом, в ней поддиректория с тремя текстовыми файлами - копиями первого
Команда ls -liR покажет для этих файлов разные inode, количество ссылок для первого файла - 4, для оставшихся (копий) - 1
После запуска ./main test_files команда ls -liR покажет что у всех 4 файлов один inode и по 4 ссылки. Изменение содержимого одного файла приведет к изменению во всех файлах
