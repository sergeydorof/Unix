Сервис имитирует наложение эффекта на изображение (но в коде вызывается только time.sleep())

http://localhost:8000/docs - Swagger для проверки функциональности сервиса (отправка запроса, ввести нужно название картинки и фильтра)
http://localhost:15672 - визуальный интерфейс брокера сообщений, логин - guest, пароль - guest

Первый запуск с тремя воркерами:  
docker compose up --build --scale worker=3

Следующие запуски с флагом -d

Для расширения количества воркеров та же команда
